TJ Teplice Letná D — aplikace výsledků
=====================================

Soubory
-------
index.html   ... otevřete v prohlížeči
data.js      ... data (musí ležet ve stejné složce)
manifest.json

Počítač
-------
Rozbalte ZIP a otevřete index.html v Chrome / Edge / Safari.

Mobil (iOS i Android) — doporučený postup
-----------------------------------------
Aplikace je webová. Na telefonu funguje nejlíp, když soubory
někam nahrajete a otevřete jako adresu https://...

1) Nahrajte celou složku teplice_d_app na:
   - GitHub Pages (zdarma)
   - Netlify Drop: https://app.netlify.com/drop  (přetáhněte složku)
   - jakýkoli webhosting / firemní web

2) Na telefonu otevřete tu adresu v prohlížeči.

3) Přidat na plochu:
   iPhone (Safari): Sdílet → Přidat na plochu
   Android (Chrome): nabídka ⋮ → Přidat na plochu / Nainstalovat aplikaci

Bez webu (jen soubor)
---------------------
ZIP si pošlete e-mailem / do Disku / WhatsApp, rozbalte
a otevřete index.html. Na iOS to umí souborové aplikace
a některé prohlížeče hůř; spolehlivější je nahrání na web.

Aktualizace dat

nahraďte celou složkou (index.html + data.js).
